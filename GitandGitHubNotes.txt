definition - : 

GitHub is a cloud-based platform used to store project source code in a centralized remote repository, so that multiple team members can collaborate on the project.

Aur simple:

GitHub = Cloud platform + Remote repository + Team collaboration

GitHub ke important kaam

1. Code hosting
Project ka source code repositories mein store karna.

2. Collaboration
Multiple developers ek project par kaam kar sakte hain.

3. Pull Request
Developer apne changes ko review ke liye submit kar sakta hai.

4. Code Review
Team members code ko review aur approve kar sakte hain.

5. Branch Protection
main jaise important branch ko direct changes se protect kar sakte hain.

6. Issues
Bug, task, feature request etc. track kar sakte hain.

7. Packages/Artifacts
Software packages aur container images ko GitHub Packages ke through manage kar sakte hain.

8. Security
Secrets, dependency/security scanning aur access controls jaise features available hain.

what is git -- git is an version control tool / software which help in tracking , managing and maintaining changes in source code.

Git ek tool hai jo aapke code mein hone wale changes ka record rakhta hai, taaki multiple versions manage kar sakein aur zarurat padne par purane version par ja sakein.

Git ka main purpose kya hai?

Git mainly 4 important problems solve karta hai:

1. Change tracking

Kaunse files mein kya change hua?

2. Version management

Purane versions/commits ko maintain karna.

3. Collaboration

Multiple developers same project par kaam kar sakte hain.

4. Recovery

Galat change hone par previous state par return/recover karna.
